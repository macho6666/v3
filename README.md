# EPUB 회차 제목 자동 변환기 v3.0

## 중복 분석 로직

### 1. 연속 제목 중복

```text
최후의 선택
최후의 선택
본문
```

판단:
- `연속중복`
- 첫 번째 제목을 `<h2>`로 변환
- 두 번째 이후 제목 문단 삭제

### 2. 같은 제목 + 같은 본문

```text
최후의 선택
A B C

최후의 선택
A B C
```

판단:
- 각 제목 뒤부터 다음 에피소드 제목 전까지 본문을 정규화
- SHA-1 해시 비교
- 해시가 같으면 `동일본문중복`
- 두 번째 제목과 중복 본문 삭제

### 3. 같은 제목 + 다른 본문

```text
우리가 사는 세계 (1)
A B C

우리가 사는 세계 (1)
X Y Z
```

판단:
- 본문 해시가 다르면 `같은제목 다른본문`
- 자동 삭제하지 않고 모두 유지
- 중복 분석 보기에서 사용자가 직접 판단 가능

### 4. 서로 다른 회차의 같은 제목

```text
720화 우리가 사는 세계 (1)
1208화 우리가 사는 세계 (1)
```

판단:
- 네이버 목록에 같은 제목이 서로 다른 회차로 존재
- EPUB 등장 순서대로 각 회차에 배정
- 둘 다 유지

## 중복 분석 보기

미리보기에서 항목을 선택하고 `중복 분석 보기`를 누르면:

- 파일명
- 앞 문단
- 현재 제목
- 뒤 문단
- 본문 미리보기
- 연속 제목 개수

를 확인할 수 있습니다.

사용자가 `모두 유지` 또는 `뒤쪽 중복 삭제`를 직접 선택할 수도 있습니다.
